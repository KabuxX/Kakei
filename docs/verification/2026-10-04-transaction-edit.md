# 取引詳細・編集ページの検証（2026-10-04）

- 詳細画面は店名の下に住所だけを表示。取引住所を優先し、未登録の場合は紐づく軌跡住所を表示。説明ラベル・地図リンク・住所操作ボタンを削除。
