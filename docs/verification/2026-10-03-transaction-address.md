# 取引詳細の住所表示

## 実装

取引詳細の「店名・取引先」の下に、保存済み軌跡でその取引IDに紐づく地点の住所を表示する。既存の日別軌跡APIを使い、同じ店名からの推測や新たな外部検索はしない。同じ地点への重複参照はまとめ、複数の地点が紐づく場合は地点名と住所をそれぞれ表示する。

住所全文は折り返し、有効な座標があれば「地図で見る」でOpenStreetMapのマーカーを新しいタブに開く。住所が空か記録日が存在しなければ住所欄を表示しない。通信失敗には再読み込みボタンを表示。取引を切り替えた後の古い応答は表示しない。

データの保存形式やバックエンドの変更なし。レシート画像だけにある住所や、未保存のagent検索候補は今回の表示対象に含まれない。

## 検証

- Front単体テスト: 22ファイル、108件成功。取引IDでの紐づけ、重複排除、住所なし、404、通信失敗からの再試行、座標なし、取引切替を検証。
- ブラウザー: 一時DBの`playwright.agent-search.config.cjs`で19件成功。固定ナビゲーションと地図リンクの重なり確認を加えた後、対象テスト1件も再実行して成功。
- Build成功。既存のMapboxチャンクのサイズ警告あり。通常サーバー用のdistも更新。
- 1440pxと375pxで目視確認。長い住所の折り返し、横方向のはみ出しがないこと、地図リンクの44px以上の高さとフォーカス表示を確認。
- 初回ブラウザーテストは幅変更前のフォーカスが残り、再フォーカスでスクロールしなかった。各幅でフォーカスを移し直し、既存のスムーズスクロール完了を待つ形にテストを修正。製品側のスクロール処理は変更していない。
