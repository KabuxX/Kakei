## 実装時の判断

1. 旧軌跡の検索失敗テストを非同期プロバイダーと有効な処理トークンを使う形式に移行。永続検索の権限検証に必要。判断が誤っている場合は元の失敗経路の回帰を見逃す可能性があるため、エラー状態と修正可能な提案を明示的に検証した。
2. 既存ブラウザテストの画像出力先を設定可能に変更。他の作業ディレクトリへの書き込みを避けるため。判断が誤っている場合は成果物の参照先に影響するが、アプリ動作には影響しない。
