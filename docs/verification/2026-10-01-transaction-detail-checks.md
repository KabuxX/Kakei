# 取引詳細ページのブラウザ確認

実施状況: 実装前、`#transaction/sample-0` をChromeで直接開いてもダッシュボードのままで、詳細表示は失敗した。以下は実装後のChrome確認結果。

## 表示と遷移

- [x] 取引名のリンクから開くと、URLがその取引の `#transaction/...` になり、内容・符号付き金額・日付・収支種別・カテゴリが一覧のデータと一致する。給与とカフェの支出で確認。
- [x] 詳細URLを直接開き、再読み込みしても同じ取引が表示される。`#transaction/sample-0` で確認。
- [x] `#transaction/%ZZ` は「取引が見つかりません」と戻るリンクを表示し、スクリプトが停止しない。
- [x] 存在しない通常IDも未発見状態を表示する。`#transaction/no-such-id` で確認。
- [x] ブラウザの戻る操作と画面の戻るリンクで、表示月・検索語・種別フィルター・一覧のスクロール位置が保たれる。元のリンクへフォーカスが戻る。検索「カフェ」・支出フィルター・スクロール位置1393.5pxを確認。
- [x] HTMLタグのような取引名は文字として表示され、要素やスクリプトとして解釈されない。`<img ...>` を入力し、詳細内の画像要素数0を確認。
- [x] 長い取引名と大きな金額でも、幅375pxでページ全体に横スクロールが出ない。`999999999` 円と長い題名で `scrollWidth=innerWidth=375` を確認。
- [x] 一覧リンクと戻る操作はアクセシビリティツリーにリンクとして現れ、詳細の見出しへフォーカスが移る。
- [x] キーボードだけでリンクと戻る操作に到達する。Tabで一覧リンク、Enterで詳細、Shift+TabとEnterで戻る操作を確認。

## 削除と外部変更

- 対象はこの作業のため `localhost:8765` に追加した3件のテスト取引（999,999,999円、別タブ確認1円、同期確認1円）。ユーザーの承認後に削除し、最後は元の16件・支出173,900円に戻した。
- [x] 削除をキャンセルすると取引と詳細表示が残る。長い名前の取引で確認後、削除前の件数19件も保持。
- [x] 削除を承認すると保存・集計が更新され、一覧へ戻る。長い名前の取引削除後は18件・支出173,902円、3件削除後は16件・支出173,900円。
- [ ] 保存時に例外が発生した場合、取引と詳細表示が残り、エラーが通知される。補助関数の単体テストで元配列の保持は確認。ブラウザの保存失敗は安全な再現手段がなく未実施。
- [x] 別タブで開いている取引を削除すると、詳細が未発見表示に変わる。「別タブ確認」を別タブで削除し、元のタブが再読み込みなしで切り替わることを確認。
