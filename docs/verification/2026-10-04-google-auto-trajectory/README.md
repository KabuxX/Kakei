## 制限

地点特定は現在取得できる店舗情報との照合であり、過去の営業実績や訪問を証明しない。Googleのブラウザ用キー未設定時は地図を表示せず時系列を残す。記録にある店舗名・支店・住所と一致しない訪問を自動保存しない。Googleの表示情報は一時表示、座標は取得から30日までのキャッシュ、恒久記録は入力情報とPlace IDのみ。

## 独立レビュー後の修正

7件の重要指摘を、再現テストの失敗を確認してから修正。引用・相談・禁止文と省略した複数日付の誤判定、作成したい/追加しての認識漏れ、海外住所の街路/都市の切り捨て、保存訪問の結果表示漏れ、地図ロード後の認証エラー通知、第三者帰属の表示漏れを修正。最終確認はbackend404/frontend157/E2E30全件成功、ビルド成功。

帰属は表示レスポンスだけに保持するため、座標キャッシュが有効でもPlace Detailsで取得する。帰属を取得できなければキャッシュ座標を地図へ配信せず、訪問記録だけを残す。追加のAPI要求と、通信不調時の一時的な地図表示制限を伴う。

実Google地図・リファラー制限・実際の認証エラー発生タイミングはブラウザ用キー未設定のため未検証。模擬Google地図とロード後認証エラーのテストでアプリ側の動作を確認。過去の店舗営業/訪問を証明するものではない。
