## 実API

ルート.envのPlacesキーをサーバー側で読み、sandbox外で実APIへ接続。キー、生のGoogle応答、利用者の取引IDは記録しない。

ファミリーマート 一の橋店（東京都港区麻布十番1-2-10）は特定成功。セブン-イレブン 千代田店（東京都千代田区二番町8-8）は住所一致・名称不一致の候補が複数返り、identity_mismatchで除外。先頭の候補を強制採用しない。

現在のSQLiteを読み取りで一時コピーし、「2026年10月1日の取引記録によって、軌跡を作って」を実行。0件保存・0件作成済み・2件除外、除外理由はidentity_mismatch、状態unchanged。利用者DBへの試験保存なし。

## 制限

地点特定は現在取得できる店舗情報との照合であり、過去の営業実績や訪問を証明しない。Googleのブラウザ用キー未設定時は地図を表示せず時系列を残す。記録にある店舗名・支店・住所と一致しない訪問を自動保存しない。Googleの表示情報は一時表示、座標は取得から30日までのキャッシュ、恒久記録は入力情報とPlace IDのみ。
