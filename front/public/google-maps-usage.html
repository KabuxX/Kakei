Google Mapsの利用・データ取扱い

Kakeiでは、取引記録の店舗名・支店名・店舗住所をGoogle Places API (New)に送信して訪問地点を検索します。取引金額・品目・会話全文はこの検索に送信しません。検索によって一つの店舗を特定できた訪問を保存し、特定できない訪問は結果に理由を表示します。

作成を指示すると確認画面を挟まず軌跡を保存します。訪問日は取引記録に基づきます。地点の特定は、その日に店舗が営業していたことや実際に訪問したことの証明ではありません。地図の線は地点間の直線で、実際の移動経路ではありません。

アプリの保存先はこの端末のサーバーです。入力された店舗情報とGoogleのPlace IDを保存します。Googleから取得した店舗名・住所・帰属情報は表示中に取得して使い、恒久的な記録にコピーしません。Googleの座標は取得から30日までの一時キャッシュで、期限切れを削除して必要に応じて再取得します。

地図表示はGoogle Maps JavaScript APIを利用します。ブラウザからGoogleへ接続するため、Googleのデータ取扱いが適用されます。地図を表示できなくても、保存した訪問の時系列を確認できます。
